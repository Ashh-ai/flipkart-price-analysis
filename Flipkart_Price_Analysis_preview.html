Flipkart Product Price & Discount Analysis¶

A Data Analytics Case Study on Pricing Strategy, Discounting Behaviour & Category Performance¶

Author: Ashray Bhasin Tools used: Python, Pandas, NumPy, Matplotlib, Seaborn Dataset: Flipkart Products Dataset — PromptCloud (Kaggle) ~20,000 real product listings crawled from flipkart.com, covering product name, category, retail price, discounted price, brand, ratings and specifications.

1. Business Problem¶

Flipkart (and any large e-commerce marketplace) lists millions of products across hundreds of categories, each priced and discounted independently by sellers. Without a data-driven view of pricing behaviour, the business risks two costly mistakes:

  • Over-discounting categories that don't need it, eroding margin.
  • Under-discounting categories where competitive pricing actually drives conversion.

As a Data Analyst, the objective of this project is to answer:

  1. Which categories dominate the catalog, and which are under/over-represented?
  2. How much discount is actually being given, and does it vary meaningfully by category?
  3. Is there a relationship between a product's price and the discount it receives?
  4. Which categories and brands carry the most "listed value" on the platform?
  5. What pricing tier does the bulk of the catalog sit in — and what does that imply for the business?

The output is a set of data-backed pricing and category recommendations, not just charts.

3. Data Cleaning & Feature Engineering¶

Raw fields aren't analysis-ready. Three problems need fixing before any pricing analysis is trustworthy:

  1. product_category_tree is a nested string like ["Clothing >> Women's Clothing >> Shorts"] — we need just the top-level category.
  2. retail_price / discounted_price have missing values that must be dropped for price analysis (can't analyze a price that doesn't exist).
  3. brand has ~2,700 missing values — filled as "Unknown" rather than dropped, since brand-less doesn't mean the product/price data is invalid.

def get_top_category(tree):
    if pd.isna(tree):
        return np.nan
    s = str(tree).strip('[]"')
    return s.split(' >> ')[0].strip().replace('"', '')

df = df_raw.copy()
df['main_category'] = df['product_category_tree'].apply(get_top_category)

# Discount metrics
df['discount_amount']  = df['retail_price'] - df['discounted_price']
df['discount_percent'] = ((df['discount_amount'] / df['retail_price']) * 100).round(2)

# Brand cleanup
df['brand'] = df['brand'].fillna('Unknown')

# Keep only rows with valid, usable price data
df = df.dropna(subset=['retail_price', 'discounted_price'])
df = df[df['retail_price'] > 0]

print("Final analyzable dataset:", df.shape)

# Price segment bucketing — useful for understanding where the catalog sits
def price_bucket(p):
    if p < 500: return 'Under ₹500'
    elif p < 1500: return '₹500 – ₹1,500'
    elif p < 5000: return '₹1,500 – ₹5,000'
    elif p < 15000: return '₹5,000 – ₹15,000'
    else: return 'Above ₹15,000'

df['price_bucket'] = df['discounted_price'].apply(price_bucket)
df.to_csv('data/flipkart_priced_clean.csv', index=False)

This is an important finding: discounting decisions on the platform appear to be driven by category/seller strategy, not by price tier, which is exactly the kind of insight that should inform a more deliberate, price-aware discounting policy.

5. Key Business Insights & Recommendations¶

# Insight Recommendation
1 Clothing + Jewellery = ~46% of all listings, but discounting is inconsistent between them Standardize a category-level discounting policy instead of leaving it to individual sellers
2 Discount intensity varies 7x between categories (Automotive 57% vs Watches 14%) Audit high-discount categories like Automotive and Clothing for margin erosion — discount depth this high may not be necessary to convert
3 Retail price has ~zero correlation (−0.06) with discount % Introduce price-aware discount bands (e.g., premium items >₹15,000 should get smaller, more deliberate discounts than they currently do)
4 53.7% of catalog sells under ₹500 Marketing and promotions should be optimized for high-volume, low-ticket conversion, not premium upsell
5 Automotive & Jewellery hold disproportionate total ₹ value vs. their listing count Prioritize these categories for inventory, seller-support and quality control — losing one listing here costs more than losing one Clothing listing
6 Median discount (47%) > mean discount (41%) A large cluster of products are being discounted very heavily — worth checking whether this reflects genuine seasonal clearance or unsustainable seller pricing behaviour

6. Conclusion¶

This analysis turned a 10,000-row raw product crawl into a set of concrete pricing and category decisions: where the catalog's volume sits, where its value sits (not the same categories), how inconsistent discounting is across categories, and the (surprising) lack of a price–discount relationship platform-wide.

Next steps if this were a live business project: join this against actual sales/conversion data to see whether the high-discount categories (Automotive, Clothing) are actually converting better than low-discount ones (Watches) — that would tell us whether the current discount strategy is working, not just whether it exists.
